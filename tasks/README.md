# Aufgaben

Die Übungen der Schulung **Agenten verbinden: MCP und A2A**. Gearbeitet wird in
diesem Repository; die Foliensätze der Schulung verweisen von der Übungsfolie
hierher.

| Aufgabe | Dauer | Worum es geht |
|---|---|---|
| [`02`](02-inspector.md) | 15 min | Den Wissensdienst im Inspector öffnen |
| [`03`](03-wissensdienst-anbinden.md) | 20 min | Den Wissensdienst an den eigenen Assistenten hängen |
| [`04`](04-rest-gegentest.md) | 15 min | Dieselbe Frage über REST — der Gegentest |
| [`05`](05-mcp-tool-erweitern.md) | 25 min | Ein MCP-Werkzeug im Kernsystem ergänzen |
| [`06`](06-agent-vorsetzen.md) | 30 min | Einen Agenten vorsetzen und bekannt machen |
| [`07`](07-orchestrator-arztservice.md) | 25 min | Orchestrator erweitern, fremden Dienst anbinden |

Die Reihenfolge ist zwingend: 03 setzt 02 voraus, 04 lebt vom Vergleich mit 03,
und 05 bis 07 bauen aufeinander auf.

**Diese Dateien sind die Quelle.** Sie lagen bis zum 01.09.2026 im
Schulungsrepo und wurden von dort gespiegelt — das lief auseinander. Wer eine
Übung ändert, ändert sie hier.
